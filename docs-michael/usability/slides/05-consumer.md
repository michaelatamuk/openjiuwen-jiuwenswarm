## What concerns them (the slide body)

This persona's own concerns — show them as a set of cards/tiles, one per group:

**Errors & Feedback** (4):

- [Error messages give no explanation or next step
- [No way to rate, retry or correct an agent answer
- [Errors don't point to the log entry with more detail
- [Rate limits and API failures hang or show nothing useful

**Conversation** (4):

- [Clarification questions appear with no context
- [Long agent replies have no structure aids
- [No immediate feedback between submit and the first chat event
- [No advance warning before context compression

**History & Notifications** (3):

- [Past conversations can't be searched
- [No notification when a long task finishes
- [Background tasks look identical to idle sessions

**Control & Continuity** (3):

- [Users aren't told what the agent is allowed to do before it acts
- [Unclear what the agent does when a session disconnects
- [A crash loses in-progress tasks with no way to resume

**Memory & Privacy** (2):

- [Users can't see what the agent has remembered
- [No way to see what personal data is sent to the model

**Help & Diagnostics** (2):

- [No single command to gather diagnostics for a bug report
- [No help or tooltips at the point of confusion
