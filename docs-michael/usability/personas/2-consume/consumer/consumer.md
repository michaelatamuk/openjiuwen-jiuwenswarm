# Consumer

*The person who uses jiuwenswarm to get things done — talks to the agent and uses its output. This is the shared base for every consumer, whatever surface they use.*

This persona is **built on top of**: none — it is the base consumer.

The findings here are grouped by what the consumer experiences. Surface-specific groups ([Web UI](../web/web-user/web-user.md), [Text](../text/text-user/text-user.md), [Channel](../channel/channel-user/channel-user.md)) add only what their own surface does differently.
