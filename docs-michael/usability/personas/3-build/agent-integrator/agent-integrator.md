# Agent Integrator

*Connects an external agent framework (Google ADK, LangGraph, CrewAI, etc.) to jiuwenswarm using the A2A protocol — making jiuwenswarm one node in a larger multi-agent system.*

The Agent Integrator communicates machine-to-machine over HTTP/JSON-RPC 2.0. There is typically no human in the loop on their side: their orchestrator dispatches tasks to jiuwenswarm and consumes the results programmatically. Their concern is not UX — it is reliability, protocol correctness, and semantic fidelity of the agent-to-agent contract.
