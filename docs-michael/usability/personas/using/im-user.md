# IM User

*A person who talks to JiuwenSwarm through a messaging (IM) app — a Feishu/Telegram/WeChat group bot — with no Web UI.*

Shares the Web User's general findings, but can only act through chat: no settings, no skill/trajectory panels, no way to stop a task from the bot. So only these findings reach you. (Not a separate matrix column — it shares the Web User mapping.)
