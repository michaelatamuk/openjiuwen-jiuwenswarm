# IM User

*A person who talks to JiuwenSwarm through a messaging (IM) app — a Feishu/Telegram/WeChat group bot — with no Web UI.*

A Chat User has no access to the Web UI: they cannot change settings, open the trajectory/skill panels, or stop a task. They are often a non-technical member of a group the bot is added to. This persona shares the general findings of the [Web User](web-user.md); the findings below are the ones that differ or bite hardest without a Web UI.

---

## Findings

*5 findings (on top of the [Web User](web-user.md) findings).*

- **[Error messages give no explanation or next step](../../findings/conversation/errors-and-feedback.md#1-error-messages-give-no-explanation-or-next-step)** — Error text is raw or empty, with no actionable fix or way to get help from chat.
- **[No notification when a long task finishes](../../findings/conversation/messages-and-history.md#2-no-notification-when-a-long-task-finishes)** — No way to be told when a long task finishes, since you can't watch the UI.
- **[Background tasks look identical to idle sessions](../../findings/conversation/messages-and-history.md#3-background-tasks-look-identical-to-idle-sessions)** — If a task keeps running, a chat member can't tell it apart from an idle session.
- **[No stop button that safely interrupts the agent](../../findings/control/stop-resume-undo.md#1-no-stop-button-that-safely-interrupts-the-agent)** — You can't safely stop an agent task that's misbehaving, because there's no stop in chat.
- **[Conversations can only be shared as a flat image](../../findings/conversation/messages-and-history.md#4-conversations-can-only-be-shared-as-a-flat-image)** — A useful exchange can only be shared as an image, not as something a colleague can reuse.
